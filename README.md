Sistema de Gestão Hospitalar - 

Sistema em Java para gestão hospitalar, desenvolvido como exercício de Programação Orientada a Objetos (POO), aplicando conceitos como herança e polimorfismo.

Sobre o projeto - 

Este projeto simula o cadastro e gerenciamento de médicos em um hospital, diferenciando tipos de profissionais (médico auxiliar e médico cirurgião) a partir de uma classe base comum.
Projeto desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (SENAI), com foco em fixar conceitos de POO.
